# Business Catalogue

A simple responsive business catalogue interface built with HTML, CSS, and JavaScript.

## Run locally

No build step is required. Clone the repository and open `Bussines catalog .html` in a browser, or serve the directory locally:

```bash
git clone https://github.com/Patric-svg/business-catalogue.git
cd business-catalogue
python -m http.server 8000
```

Open <http://localhost:8000/Bussines%20catalog%20.html>.

## Project goals

- Present business information in a clear catalogue layout.
- Demonstrate browser-side interaction and responsive styling.
- Provide a small foundation for adding search, filtering, and data-backed listings.

## Status
